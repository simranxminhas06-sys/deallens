# Sample data: Amazon / Whole Foods Market (2017)

These three files are **synthetic demo documents**, not actual SEC filings. They summarize
publicly known facts about the 2017 Amazon–Whole Foods acquisition (revenue figures, deal
terms, store counts, strategic context) in a simplified, section-numbered format so the
DealLens pipeline has something realistic to cite against, without redistributing any
company's actual annual report or investor deck text.

To run DealLens against a different, real deal: replace these with the acquirer's and
target's actual 10-K excerpts, investor presentations, or press releases (PDF or text),
and update `transaction_assumptions.md` accordingly. Only use documents you have the right
to use — avoid confidential or non-public information.

Facts here are approximate and rounded for demo purposes; do not cite this data as precise
historical record.
